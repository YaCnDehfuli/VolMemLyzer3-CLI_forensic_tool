# Security policy

Report vulnerabilities in this repository privately to
**dehfouliyasin@gmail.com**. Please do not open a public GitHub issue for
exploitable findings.

There is no bug bounty.

VolMemLyzer3 parses memory images, which are attacker-influenced input.
Reports about how plugin output, paths, or caches are handled are
especially welcome. I will acknowledge reports as soon as I can.
